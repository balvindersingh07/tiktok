# Tashan (Rainbow Edition)

A high-performance, short-form vertical video social platform rewritten from Android to modern React with Vite, TypeScript, and Tailwind CSS.

## Features

- **Immersive Video Feed**: Full-screen vertical swipe feed with Following & For You algorithms, double-tap floating hearts, like/comment/bookmark/share interactions, and audio synthesizer integration.
- **Discover & Search**: Real-time multi-filter search (Videos, Creators, Sounds), trending hashtag carousels, and bento video grids.
- **Creation Studio**: Video recording, media upload, speed adjustments, camera effects/filters, sound track selector, duet & stitch modes, and drafts management.
- **Inbox & Direct Messages**: Real-time notifications for likes, comments, and followers, alongside active user presence and interactive direct messaging.
- **User Profiles & Account Switcher**: Multi-account management with PIN authentication, video grids (My Videos, Liked, Bookmarks, Private, Drafts), and profile editing.
- **Local Backend Diagnostics Console**: In-memory and localStorage persistence mimicking Android Room database, local cache monitoring, recommendation algorithm weights, and live request logs.
- **Sound Detail & Video QR Dialog**: Full sound inspection with procedural audio playback and clip QR code generator.

## Tech Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS with custom Tashan Rainbow gradients and animations
- **Icons**: Lucide React
- **Audio**: Web Audio API Sound Synthesizer
